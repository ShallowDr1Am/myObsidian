**var 与 let的比较在于作用域**和 变量是否提升

var的作用域是函数作用域，let是块作用域

```
if (true) {
    var message = "hi";
    console.log(message); // hi
}
console.log(message); // hi


if (true) {
    let message = "hi";
    console.log(message); // hi
}
console.log(message); // error: message is not defined
```

message变量之所以不能在 if 块外部被引用，是因为它的作用域仅限于该块内部。块作用域是函数作用域的子集，因此适用于var的作用域限制同样也适用于let。

const主要与let相比

const的行为与let基本相同，唯一一个重要的区别是：用const声明变量时必须同时初始化变量，且尝试修改const声明的变量会导致运行时报错：

```
const a; // error: 必须初始化 "const" 声明

const b = 250;
b = 520; // error: 无法赋值给 "b" ，因为它是常数
```

注意，const声明的限制只适用于它指向的变量的引用，换句话说，如果const变量引用的是一个对象，那么修改这个对象内部的属性并不违反const限制：

```
const obj = { x: 666 };
obj.x = 888; // ok
obj.y = '啊哈哈'; // ok
```


1.声明方式不同，箭头函数为匿名函数（更加简洁）

2.this指向不同 箭头函数指向的是上级作用域，并且箭头函数的this不会因为call、apply、bind改变

```
// ES6
function foo() {
  setTimeout(() => {
    console.log('id:', this.id);
  }, 100);
}

// ES5
function foo() {
  var _this = this;

  setTimeout(function () {
    console.log('id:', _this.id);
  }, 100);
}
```

3.箭头函数也没有prototype，arguments 所以无法构造函数，但可以利用rest替代arguments（...rest）=>{}(rest比prototype更加灵活)

4.箭头函数无法重复函数的参数命名

```
function fn(name,name) {
    console.log('fn2:',name)
}
let fn2 = (name,name) => {
    console.log('fn',name)
}
fn('nan','jiu') // 'jiu'
fn2('nan','jiu') // 报错
```
