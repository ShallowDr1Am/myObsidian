VS
缓存存储位置
01
Service Worker
独立线程，可编程控制缓存策略，拦截请求
02
Memory Cache
内存缓存，读取快但不关心 Cache-Control，匹配时校验 Content-Type/CORS
03
Disk Cache
硬盘缓存，根据 HTTP Header 判断资源是否缓存，容量大
04
Push Cache
HTTP/2 推送缓存，连接关闭即释放，只能使用一次
优先级从高到低 ▼

缓存策略：按文件类型配置
HTML
主文件 — 协商缓存
Cache-Control: no-cache
保证改变能及时更新
Images
图片 — 短期强缓存
Cache-Control: max-age=86400
1天过期，替换为主
CSS
样式 — 长缓存 + 指纹
filename.[hash].css
max-age=31536000 + 文件名哈希
JavaScript
脚本 — 类似CSS策略
Cache-Control: private, max-age=31536000
含隐私信息时添加 private
