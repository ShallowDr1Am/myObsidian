# AI 助手代码解析 · 阅读地图

对象：`S-ServicesCmdb/S-ops-tool-service`，启动类 `com.didi.OpsToolApplication`，Java 8 / Boot 2.7.17。
核心支点：模型提交 `calls + dataFlows`（边由模型提议）→ `ToolGraphCompiler` 编译校验 → 执行。这是与 LangGraph（开发者写边）的唯一根本差异。

## 规模

| 包 | 文件 | 行数 | 职责 |
|---|---:|---:|---|
| `com.didi.ai` | 573 | 46318 | 渠道/编排/规划/记忆/知识/交付 |
| `com.didi.cmdbtool` | 218 | 19944 | 业务工具，10 个域 |
| `com.didi.taskgraph` | 63 | 6363 | 契约/编译/执行/续跑 |
| `com.didi.toolruntime` | 61 | 6325 | 注册/目录/Provider/门禁/MCP |

## 架构

```
渠道层      assistantapi / webchat / dc / difychat / cooper
应用编排层   UnifiedToolChatService → UnifiedTaskGraphEngine
规划层      planning/tool（5730 行）+ skill
图引擎层    taskgraph：契约 → 编译 → 执行 → 绑定 → 续跑
工具运行时   toolruntime 门禁 + cmdbtool 取数
横切        llm / memory / knowledge+rag / interaction / progress / export
```
