# Go 组合原则

Go 没有继承，通过**结构体嵌入**和**接口组合**实现代码复用。

## 核心语法

```go
// 定义结构体
type Animal struct {
    Name string
}

// 定义可嵌入的能力
type Swimmer struct{}

func (s Swimmer) Swim() { fmt.Println("游泳") }

// 组合：嵌入多个结构体
type Duck struct {
    Animal   // 嵌入基础结构体
    Swimmer  // 嵌入能力
}
```

## 使用示例

```go
duck := Duck{Animal: Animal{Name: "鸭子"}}
duck.Eat()  // 调用 Animal 的方法
duck.Swim() // 调用 Swimmer 的方法
```

## 接口组合

```go
type Reader interface { Read() }
type Writer interface { Write() }

// 组合接口
type ReadWriter interface {
    Reader
    Writer
}
```

## 组合 vs 继承

| 组合 | 继承 |
|------|------|
| has-a 关系 | is-a 关系 |
| 灵活组装 | 层级固定 |
| 避免深层嵌套 | 容易产生复杂继承链 |

## 关键点

- 嵌入结构体的方法会被自动提升
- 可覆盖嵌入结构体的方法
- 接口也可组合，小接口组合成大接口
