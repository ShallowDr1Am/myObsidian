## 关键事实

- 启动类仅 `@EnableDubbo`，业务代码 0 个 Dubbo 消费引用；pom 里的 dubbo API jar 未用于消费。
- 出站 HTTP 客户端混用：`cmdbtool` 内 HttpURLConnection / HttpClient / RestTemplate 三种。
- 规划层 `planning/tool` 33 文件 5730 行；interaction 33 文件 2350 行；memory 60 文件 3421 行。
- 技能定义随制品发布：`ai/skill/SourceControlledSkillDefinitionSource`（Reviewed definitions shipped with the application artifact）+ `resources/ai/platform-features.json`。
