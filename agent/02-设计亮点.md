                              targetCallId, targetInputPort } // 边=数据流

## 边的声明式策略（对比 LangGraph 条件边）

```java
WorkflowEdgeContract { sourceRoleKey, sourceOutputPort,
                       targetRoleKey, targetInputPort,
                       purpose, required,
                       onEmpty, onMulti, onNull }   // 分支策略是数据，不是代码
NodeRole          { TARGET, SUPPORT }
CompletionPolicy  { ALL_REQUIRED, PARTIAL_ALLOWED }
```

LangGraph 的分支是 `addConditionalEdges(函数)`；这里分支策略写在契约里，由执行器解释。
