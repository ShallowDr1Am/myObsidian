# 当前选型：今天的框架能做什么

核实日期 2026-11-17，来源为官方文档与 GitHub。

## 版本与成熟度

| 框架 | 版本 | Java 基线 | 关键事实 |
|---|---|---|---|
| Spring AI | 2.0.2 | 17+（Boot 4.x） | 官方指南《Building Effective Agents》实现 Anthropic 五模式（Chain/并行/路由/Orchestrator-Workers/评估-优化），明确背书企业场景工作流优先 |
| LangChain4j | 持续迭代 | 17+ | 20+ 模型、30+ 向量库；AiServices/Agents/Skills；RAG 全链路（查询改写/路由/重排/RRF）；Spring Boot/Quarkus/Helidon/Micronaut 集成 |
| LangGraph4j | 1.9.9（2026-11-07） | 17+（1.8.x LTS） | 2112 stars，核实前一日仍有提交；同时集成 LangChain4j 与 Spring AI；MIT |

## Spring AI ↔ infra 手写件对照

| infra 手写件 | Spring AI 对应物 | 覆盖度 |
|---|---|---|
| llm 客户端/SSE/协议（2161 行） | ChatClient + ChatModel | 完整（凭证治理除外） |
| tool calling 传输 | Tool Calling + ToolCallingAdvisor | 完整 |
| ToolCandidateRetriever 候选召回 | Tool Search Tool / Dynamic Tool Discovery | 机制完整 |
| 参数校验 | Structured Output Schema Validation & Self-Correction | **仅单次输出，不管图级数据流** |
| 基础对话记忆 | Chat Memory API | **仅窗口式，不管焦点/语义召回** |
| rag 切块/向量化/检索（1352 行） | ETL Pipeline + PGvector VectorStore | 完整 |
| HttpMcpBrokerClient（1247 行） | MCP Client/Server Boot Starters | 完整 |
| debug trace | Observability（Micrometer） | 部分 |

## LangGraph4j ↔ taskgraph 对照

| LangGraph4j | infra 对应物 |
|---|---|
| StateGraph + compile() → CompiledGraph | ToolGraphCompiler → CompiledToolPlan |
| AgentState + Channel.Reducer | ToolResultBindingEngine |
| 条件边（EdgeAction 函数） | WorkflowEdgeContract onEmpty/onMulti/onNull |
| CheckpointSaver | ToolGraphInterruptionSnapshot + continuation |
| 异步/流式 | SSE + web-chat-stream |
| Studio 可视化调试 | 无对应物（白赚） |

**边界：LangGraph4j 的边仍由开发者代码定义。不提供「模型提议边 + 编译期准入」、权限、审计、工具契约。**

## 推荐组合与坐标

```
Spring AI 2.x（接入）+ LangGraph4j（图执行/checkpoint）+ 自研治理（planner/准入/权限/审计/渲染）
```

```xml
<!-- Spring AI：OpenAI 兼容端点（企业模型网关适用） -->
<dependency>
  <groupId>org.springframework.ai</groupId>
  <artifactId>spring-ai-starter-model-openai</artifactId>
</dependency>
<!-- LangGraph4j -->
<dependency>
  <groupId>org.bsc.langgraph4j</groupId>
  <artifactId>langgraph4j-core</artifactId>
  <version>1.9.9</version>
</dependency>
```
