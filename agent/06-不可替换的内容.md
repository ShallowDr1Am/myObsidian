# 不可替换的内容

判断标准：**换个框架，这段代码还在吗？** 还在 = 不可替换。
核心代码约 7.9 万行（ai 46318 + cmdbtool 19944 + taskgraph 6363 + toolruntime 6325），不可替换约八成。路径相对 `src/main/java/com/didi/`。

## 一、治理层（框架不替你做决定）

| 资产 | 位置 | 规模 | 不可替换原因 |
|---|---|---:|---|
| 工具契约 + 准入 | `taskgraph/workflow/contract/`、`taskgraph/compilation/`、`planning/tool/` 准入部分 | ~2000 行 | modelWritableInputPointers/inputSourceConstraints/PlanAdmissionProfile 是「模型被允许做什么」，框架只管图结构 |
| 权限门禁 | `toolruntime/{gateway,validation,governance}` + `ai/adapter/toolruntime/authorization/` | 4265 行+ | 答案来自 CMDB 用户角色体系，双检是故意的 |
| 来源追溯 | InputSource 四值 + InputProvenanceSnapshot | — | 企业合规审计要求 |
| 确定性渲染 | `ai/presentation/`（HostComparisonHtmlRenderer/QueryListDelivery） | 1415 行 | ADR-013 防数字被模型改；报告形状是业务的 |
| 写操作安全 | `ai/interaction/` 语义部分 | ~1500 行 | 草稿/预览/确认/幂等是工单业务规定动作 |

## 重建姿势
